# Enterprise customer-lab acceptance (Batch K)

Enterprise production acceptance is customer-hosted and customer-controlled.
Evidence must cover tenant-isolation negative tests, device identity/revocation,
authenticated lease expiry, database backup/restore, TLS and secret rotation,
operator audit, resource admission/opt-out, and explicit customer lab sign-off.

This checklist is not a certification and does not replace penetration testing,
disaster-recovery exercises or customer risk acceptance. Attach immutable test
runs, deployment topology, software versions, test data handling and remediation
records. UJANI must not require a vendor-operated central control plane.
