# Collective Defence dual opt-in policy (Batch J)

Collective Defence is secondary to Enterprise's customer-hosted resource-sharing
purpose and remains disabled unless both the organization and each participating
device owner opt in. Only allowlisted defensive indicators may be shared. Raw
file content and personal data are prohibited, and operator approval is required.

This policy does not deploy agents, quarantine devices, block traffic, or perform
remediation. Any future response action must be a separate capability with its
own authorization, audit trail, rollback and customer-selected security tooling.
A production integration must prove that opt-out immediately stops sharing and
that no payload is transmitted when either consent is absent.
